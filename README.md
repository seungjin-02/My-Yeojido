# 나의 여지도

실제 경계를 도시 단위로 묶은 지도에 여행 기록을 남기는 한국어 웹앱. React 19, TypeScript, Vite 8, MapLibre GL JS 6. 서버와 계정 없이 각 방문자의 브라우저에 기록을 저장합니다.

[공개 사이트](https://seungjin-02.github.io/My-Yeojido/) · [배포 상태](https://github.com/seungjin-02/My-Yeojido/actions/workflows/pages.yml)

## GitHub Pages 배포

`main`에 코드를 push하면 GitHub Actions가 잠긴 의존성을 설치하고 테스트·타입 검사·빌드를 통과한 뒤 사이트를 배포합니다. PR에서는 검증만 수행합니다. Node.js 버전은 `.node-version`에 고정했습니다. 공식 GitHub Actions는 검증한 커밋에 고정했으며 별도 배포 토큰이나 API 키가 필요하지 않습니다.

프로젝트 경로 `/My-Yeojido/`는 워크플로의 빌드 인자로 지정합니다. 저장소 이름이나 배포 경로를 바꾸면 이 인자와 공개 URL을 함께 바꿔야 합니다.

```powershell
npm ci
npm test
npm run build -- --base=/My-Yeojido/
npm run preview -- --base=/My-Yeojido/
```

기존 사이트에서 기록을 옮기려면 **더보기 → 기록 내보내기**로 JSON을 저장한 다음, 이 사이트에서 **기록 가져오기**를 사용하세요. 사이트 주소가 달라 기존 브라우저 기록은 자동으로 옮겨지지 않습니다. 기존 사이트의 기록을 지울 필요는 없습니다.

## 실행

Node.js 24 권장.

```powershell
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173/ 에 접속합니다. `npm run build`는 타입 검사와 정적 배포 파일 생성을 수행합니다. 결과는 `dist/`이며 GitHub Pages를 포함한 HTTPS 정적 호스팅으로 공개할 수 있습니다.

## 제공 기능

- 2026-10-01 기준 162개 도시·도서 단위의 실제 경계. 코드 기반 검색, 필터, 확대·축소·전국 보기.
- 방문 기록 추가·수정·삭제, 날짜 미상, 500자 메모, 명소 선택, 독립 북마크.
- 기록에서 파생되는 지역·명소 방문 상태와 전체 진행도.
- 브라우저 저장·복원, 5MiB 상한의 JSON 내보내기·검증 후 전체 교체 가져오기.
- 나만의 명소 추가·수정·삭제·복원. 기본 명소도 내 브라우저에서 편집할 수 있습니다.
- 10개 여행권으로 주변 도시를 함께 탐색하며 방문 집계는 도시별로 유지합니다.
- 울릉도·독도 독립 선택, 실제 위치 표식과 함께 보기. 모바일 하단 패널과 키보드 검색.
- 기본 명소 56곳, 여행권 10곳의 상세 설명·활동 제안·대표 명소와 출처. 안내에서 방문 기록으로 연결합니다.
- 기본 분류 7개와 사용자 분류(총 30개까지). 여행지마다 복수 분류와 대표 색상 선택. 20색 팔레트·색상 선택기·HEX 입력.
- 방문 여부·전체 분류·개별 분류로 지도 색상 전환, 내 여행지에서 필터·검색·방문 횟수순 모아보기.
- 여러 번 간 곳은 같은 도시의 방문 기록 2개부터 자동 포함. 현재 기록과 분류에서 계산하는 업적 52개와 진행도·종류별 필터·검색.


데이터 참조·파생 상태·가져오기 검증·저장 실패·탭 충돌을 단위 테스트로 확인합니다. 실제 수행한 브라우저 검증은 `VERIFICATION.md`를 참고하세요. 별도 린터는 구성하지 않았습니다.

## 데이터·개인정보

출처·라이선스·원본 고정 리비전·가공 명령은 `DATA_SOURCES.md`에 기록했습니다. 외부 지도 타일·API 키·폰트 CDN 없이 동작합니다. 지도 워커도 자체 배포합니다. 작은 도서의 위치와 원본 경계 좌표를 유지합니다.

여행 기록은 해당 사이트 주소의 localStorage에만 저장됩니다. 서버 전송·계정·기기간 동기화·사진 업로드는 제공하지 않습니다. 브라우저 데이터 삭제 전 JSON으로 백업하세요. 로컬 미리보기와 공개 사이트는 주소가 달라 저장공간도 다릅니다. 여러 탭의 변경은 반영하고 폼 저장 시 충돌을 감지하지만 완전한 동시 트랜잭션은 보장하지 않습니다.

손상되거나 지원하지 않는 저장 데이터를 자동 덮어쓰지 않습니다. 원문 백업 후 검증된 백업 가져오기로 복구할 수 있습니다. 저장 형식 v1·v2 백업은 v3로 읽으며, 이전 도시별 기록은 명시적 코드 매핑으로 통합 지역에 연결합니다. 기존 울릉군 기록은 방문한 섬을 사용자가 고를 때까지 보존합니다.

명소 편집은 `placeOverrides`, 삭제는 `hiddenPlaceIds`로 저장합니다. 삭제 시 북마크를 해제하고 과거 방문 기록과 명소 이름은 보존합니다. 기록·명소·편집·삭제 상태를 JSON으로 함께 백업합니다.

분류·색상 설정도 v3 백업에 포함합니다. 업적은 별도로 저장하지 않고 현재 기록에서 계산하므로 삭제·수정 시 진행도도 바뀝니다. 계절·연도 업적은 실제 방문일이 있는 기록만 사용합니다. 여행권 안내는 편집 콘텐츠로, 개인이 수정한 명소 목록과 구분됩니다. 내 목록에서 삭제한 명소는 복원한 뒤 안내에서 기록할 수 있습니다.


## 화면과 통계 개편

주 메뉴는 나의 지도 / 여행 통계 / 내 여행지 / 업적입니다. 기존 날짜별 기록의 수정·삭제는 내 여행지의 방문 기록 관리와 각 지역의 기록 보기에서 제공합니다.

- 여행 통계: 총 방문 기록, 방문 도시, 다시 간 지역, 고유 방문 명소. 방문 연도 선택과 월별 방문 기록, 지역별 탐방률, 재방문 순위, 분류별 취향.
- 월별 통계는 실제 방문일을 사용합니다. 날짜 미상과 방문 섬 선택을 보류한 이전 기록은 명시적으로 제외·안내합니다. 여행 횟수는 기록 수를 뜻하며 날짜나 도시를 자동으로 하나의 여정으로 합치지 않습니다.
- 추천 팔레트: 세이지 가든 / 오트밀 노트 / 안개 바다. 20색 팔레트·색상 선택기·HEX 입력은 유지합니다. 테마는 기본 분류의 색을 바꾸고 사용자 분류와 이름은 보존합니다.
- 이전의 기본 색과 정확히 일치하는 색만 새 기본 색으로 읽습니다. 다른 사용자 지정 색은 유지합니다. 로딩만으로 저장 원문을 덮어쓰지 않습니다.
- 업적 52개: 탐방, 다시 찾기, 취향, 명소와 기록, 계절과 시간, 여행권. 달·요일·계절은 실제 방문일 기준이며 같은 날짜 중복 기록은 요일 업적에서 하루로 셉니다.
- 지도 양쪽은 사용자 피드백에 따라 기존의 작은 부유형 배치와 카드 크기를 유지합니다. 왼쪽 중단·하단 안내는 배치를 키우지 않고 11~12px 중심으로 대비와 크기를 소폭 보완했습니다. 통계·업적·설정 창은 별도의 새 UI를 적용합니다. 시스템 한국어 폰트를 유지합니다.


팔레트는 채도가 낮고 밝은 20색으로 구성합니다. 이전 제공 테마의 색과 일치하는 기본 분류·방문색은 대응하는 새 테마 색으로 읽고, 사용자 분류와 다른 직접 지정 색은 유지합니다. 색상 선택기의 선택 표시는 어두운 잉크색으로 구분합니다. 지도 양쪽의 배치와 크기는 그대로입니다.

지역별 통계에서 통합 광역도시는 `provinceName`에 상위 국가명(대한민국)을 가지므로 해당 단일 도시의 이름을 표시합니다. 다른 시·도는 기존 이름과 집계를 유지합니다.
